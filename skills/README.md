# Agent skills

This repository publishes reusable agent instructions alongside the library.

Install the Unthrown skill with:

```sh
npx skills add btravstack/unthrown --skill unthrown
```

The skill is intentionally procedural rather than a copy of the API reference:
it teaches an agent how to classify failures, qualify boundaries, match errors
exhaustively, and verify its work. The versioned documentation remains the
source of truth for symbols and signatures.
